# Logoped Site

Современный сайт для логопеда-дефектолога.

Проект создаётся как полноценная онлайн-платформа для работы специалиста с учениками и родителями.

---

# Основная идея проекта

Сайт должен объединять:

- информацию о специалисте;
- запись на онлайн-занятия;
- личный кабинет ученика;
- расписание занятий;
- методические материалы;
- игровые упражнения;
- конкурсы учеников;
- панель управления специалиста.

---

# Правила разработки


## Не изменять структуру без необходимости.

Перед созданием новых файлов проверить:

- можно ли использовать существующий;
- не дублирует ли он текущую функцию.


---

## Сначала делается:

1. Интерфейс.
2. Логика страниц.
3. Подключение базы данных.
4. Авторизация.
5. Реальные функции.


---

## Не подключать оплату раньше времени.

Сначала реализовать:

- запись;
- подтверждение специалистом;
- учёт занятий.


После этого добавлять оплату.

# Главная цель проекта

Создать полноценный сайт логопеда, который сможет заменить ручное ведение клиентов:

родитель → регистрация → запись → оплата → занятия → материалы

специалист → управление → подтверждение → контроль учеников
